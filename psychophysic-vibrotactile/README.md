# psychophysic-vibrotactile

振動刺激の検出閾値（どれだけ弱い振動まで感じられるか）を測る心理物理実験のサンプルです。
ターミナル上で動き、参加者はキーボードで回答します。

| ファイル | 方法 |
|---|---|
| method_of_limits.py | 極限法（上昇系列・下降系列を交互に提示） |
| staircase.py | 階段法（回答に応じて振幅を上下させる適応法） |

## 実行

```
cd psychophysic-vibrotactile
python method_of_limits.py
python staircase.py
```

1. 何かキーを押すと開始
2. 「準備 ...」→「■■■■■ 振動中 ■■■■■」の間に振動が提示される
3. 感じたら `y`、感じなければ `n`（Enter は不要）。`q` で中断
4. 終了後、試行ごとの振幅がバーグラフで表示され、閾値が出力される
5. 結果は `results/<SUBJECT>_limits_日時.csv` / `results/<SUBJECT>_staircase_日時.csv` に保存

## 変更する変数

プログラム冒頭の大文字の変数を書き換えて使います。

**共通**

| 変数 | 意味 |
|---|---|
| `SUBJECT` | 参加者 ID（ファイル名に使用） |
| `DEVICE`, `CHANNEL` | 出力デバイス番号（`sd.query_devices()` で確認）と L/R |
| `FREQUENCY`, `DURATION` | 振動周波数 [Hz]、刺激時間 [s] |
| `READY_TIME`, `ITI` | 準備表示から刺激までの時間、試行間隔 [s] |
| `YES_KEY`, `NO_KEY`, `QUIT_KEY` | 回答・中断キー |

**極限法 (method_of_limits.py)**

| 変数 | 意味 |
|---|---|
| `START_LOW`, `START_HIGH` | 上昇系列・下降系列の開始振幅 |
| `STEP` | 振幅の刻み |
| `N_SERIES` | 系列数（上昇 → 下降 → 上昇 …） |

上昇系列は初めて「はい」、下降系列は初めて「いいえ」と答えた時点で終了し、
その直前の振幅との中点を系列の閾値とします。全系列の平均が閾値です。

**階段法 (staircase.py)**

| 変数 | 意味 |
|---|---|
| `START_AMPLITUDE` | 開始振幅 |
| `STEP` | 振幅の刻み |
| `N_DOWN` | `1` = 1up-1down（50% 検出点）、`2` = 1up-2down（70.7% 検出点） |
| `N_REVERSALS` | 反転がこの回数に達したら終了 |
| `N_DISCARD` | 閾値計算で捨てる最初の反転数 |
| `MAX_TRIALS` | 最大試行数 |

「いいえ」なら振幅を `STEP` 上げ、`N_DOWN` 回連続「はい」なら `STEP` 下げます。
上げ下げの向きが変わった点（反転点）のうち、最初の `N_DISCARD` 個を除いた平均が閾値です。

## 注意

- 振幅はオーディオ出力の値（0〜1）です。物理的な変位・加速度にするにはアンプと振動子の特性を測定して換算してください。
- 刺激の音が聞こえると回答の手がかりになるため、ヘッドホンでホワイトノイズを流すなどして遮音してください。
- macOS / Linux / Windows のターミナルで動作します（IDE の出力ウィンドウではキー入力が取れない場合があります）。
